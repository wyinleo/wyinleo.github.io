# Teaching information

The Teaching page at `/lessons/` displays course names, terms, class schedules,
classrooms, and the external course-materials link in English. Edit these fields
in `_data/lessons.yml`; `_includes/course-info.html` renders the information on
both the Teaching page and existing course URLs.

Course materials are available through Zhihuishu using the listed course code.
The first three lecture PDFs and their public download links were removed from
the current repository in October 2026. Do not add lecture PDFs to the public site.

Run `bundle exec jekyll build` to validate changes before publishing.
